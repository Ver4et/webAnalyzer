# Web Analyzer

Небольшой веб-сервис для быстрой проверки SEO-метаданных и внутренней структуры сайта.

Web Analyzer открывает страницу в браузере, анализирует ее итоговый HTML и показывает:

- заголовок страницы и SEO-метаданные;
- `description` и `keywords`;
- Open Graph title и description;
- подключенные CSS-файлы;
- количество встроенных стилей;
- количество внутренних ссылок;
- первые дочерние страницы и их основные данные.

## Возможности

Интерфейс включает:

- адаптивную форму для анализа URL;
- автоматическое добавление `https://`, если схема не указана;
- индикатор выполнения запроса;
- три визуальные темы: Default, Retro и Dark;
- отображение результатов в виде подробных блоков и дерева ссылок;
- обработку ошибок некорректного URL и недоступных страниц.

## Установка

Требуется Node.js 18 или новее.

```bash
npm install
```

Puppeteer использует установленный Google Chrome в Windows. Если системного браузера нет, установите браузер Puppeteer вручную:

```bash
npx puppeteer browsers install chrome
```

Для запуска с другим Chromium или Chrome задайте путь к исполняемому файлу:

### Windows PowerShell

```powershell
$env:PUPPETEER_EXECUTABLE_PATH = "C:\Path\To\chrome.exe"
```

### macOS или Linux

```bash
export PUPPETEER_EXECUTABLE_PATH=/path/to/chrome
```

## Запуск

```bash
npm start
```

После запуска откройте в браузере:

```text
http://localhost:3000
```

Порт можно изменить через переменную окружения `PORT`.

### Windows PowerShell

```powershell
$env:PORT = 8080
npm start
```

## API

### `POST /bold-url`

Запускает анализ страницы.

Пример запроса:

```bash
curl -X POST http://localhost:3000/bold-url \
	-H "Content-Type: application/json" \
	-d '{"url":"https://example.com"}'
```

Тело запроса:

```json
{
	"url": "https://example.com"
}
```

Ответ содержит данные исходной страницы и массив `children` с пятью первыми внутренними ссылками. Для каждой дочерней страницы дополнительно анализируются до трех вложенных ссылок.

Основные поля ответа:

| Поле | Описание |
| --- | --- |
| `url` | Адрес проанализированной страницы |
| `title` | Содержимое тега `title` |
| `metaDescription` | Значение `meta[name="description"]` |
| `metaKeywords` | Значение `meta[name="keywords"]` |
| `ogTitle` | Значение `meta[property="og:title"]` |
| `ogDescription` | Значение `meta[property="og:description"]` |
| `cssLinks` | Список подключенных таблиц стилей |
| `inlineStylesCount` | Количество тегов `style` |
| `sum_links` | Количество уникальных внутренних ссылок |
| `children` | Данные первых дочерних страниц |

## Ограничения

- Поддерживаются только URL со схемами `http` и `https`.
- Для анализа страницы отводится до 20 секунд.
- В дочерние страницы попадают только первые пять внутренних ссылок.
- Внешние ссылки, якоря, `mailto:`, `tel:`, `javascript:` и `data:` не учитываются.
- Локальные, loopback, private, link-local и другие служебные IP-адреса заблокированы.
- API принимает не более 20 запросов за 15 минут с одного IP-адреса.
- Сайт должен быть доступен серверу, на котором запущено приложение.

## Коды ошибок

| Код | Причина |
| --- | --- |
| `400` | URL не указан, имеет неверный формат или использует неподдерживаемую схему |
| `429` | Превышен лимит запросов |
| `500` | Ошибка загрузки или обработки страницы |
